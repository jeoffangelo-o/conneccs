## Color Coding

- **Green (✅)**: Submitted status
- **Orange (⚠️)**: Not submitted / Pending
- **Accent Blue**: Action buttons, stars in rating boxes
- **Green Highlight**: Average rating box (stands out!)

---

## Interactive Elements

### Buttons You Can Click:
1. **"Rate My Submission"** - Opens rating modal (only shows if not rated yet)
2. **"Preview"** - Opens document preview modal
3. **"Download"** - Downloads template file
4. **Card itself** - Opens folder view with full details

### Input Fields in Modal:
1. **Quality Rating** - Type 1-5, see stars appear live
2. **Timeliness Rating** - Type 1-5, see stars appear live
3. **Remarks** - Optional text field

## Troubleshooting

### "I don't see the changes!"
→ **Solution**: Hard refresh with `Ctrl+Shift+R` (Windows) or `Cmd+Shift+R` (Mac)

### "Template section is not showing!"
→ **Solution**: It should always be visible now. Hard refresh and check again.

### "Rating modal doesn't open!"
→ **Solution**: Make sure you uploaded a document first. The button only appears after upload.

### "Stars don't appear when I type!"
→ **Solution**: Make sure you're typing a number between 1-5. Stars appear instantly.

### "Average rating is wrong!"
→ **Solution**: Average = (Quality + Timeliness) / 2. Example: (4+5)/2 = 4.5
