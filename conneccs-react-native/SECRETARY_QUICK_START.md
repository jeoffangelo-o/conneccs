## ⭐ How to Rate (Step-by-Step)

### 1. Click "Rate This Target"
Modal opens with target details

### 2. Enter Ratings (1-5 scale)
```
Quality (Q):     [5]  ← Type number 1-5
Efficiency (E):  [4]  ← Type number 1-5
Timeliness (T):  [5]  ← Type number 1-5

Computed Average: 4.67
```

**Rating Scale:**
- **5** = Outstanding
- **4** = Very Satisfactory
- **3** = Satisfactory
- **2** = Unsatisfactory
- **1** = Poor

### 3. Choose Action

**Option A: Rate & Forward to Dean** ✅
- Target goes to Dean for approval
- Faculty is notified

**Option B: Mark Incomplete** ❌
- Enter note: "Please upload evidence..."
- Target returns to faculty
- Faculty must revise and resubmit

---

## 🎯 When to Rate vs Mark Incomplete

### ✅ RATE if:
- Accomplishment is clear
- Documents are uploaded
- Target was completed
- Evidence supports the claim

### ❌ MARK INCOMPLETE if:
- No documents uploaded
- Vague accomplishment description
- Target not actually completed
- Need more information

## 🚫 Common Mistakes to Avoid

### ❌ Don't:
- Rate without checking documents
- Use same rating for everyone
- Rate your own IPCR
- Rate the Dean's IPCR
- Rush through reviews

### ✅ Do:
- Check evidence first
- Be fair and consistent
- Provide clear notes when marking incomplete
- Take time to review properly
- Compare accomplishment to target

## ⚡ Quick Tips

### 1. Start with Compliance Tab
Check who has submitted → Know how much work you have

### 2. Review Documents First
No documents = Mark incomplete immediately

### 3. Compare to Self-Rating
If faculty rated 5/5/5 but work is average → Rate honestly

### 4. Be Specific in Notes
❌ Bad: "Incomplete"  
✅ Good: "Please upload attendance sheets and training materials"

### 5. Rate in Batches
Set aside time to rate multiple targets at once

## 🆘 Troubleshooting

### "No targets awaiting rating"
**Why:** Faculty haven't submitted yet  
**Fix:** Check Compliance tab, send reminders

### "Cannot rate this target"
**Why:** It's your own or Dean's IPCR  
**Fix:** Skip it, someone else will rate

### "Invalid rating"
**Why:** Number not between 1-5  
**Fix:** Enter 1, 2, 3, 4, or 5

### Target disappeared after rating
**Why:** It moved to Dean's queue (correct!)  
**Fix:** Nothing, this is normal
