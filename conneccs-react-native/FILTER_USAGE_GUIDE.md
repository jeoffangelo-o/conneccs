# IPCR Filter Usage Guide

## Quick Reference

### Filter Options

**Category Filter:**
- 🔵 All - Show all categories
- 🔴 Strategic - Strategic functions only
- 🟢 Core - Core functions only  
- 🟠 Support - Support functions only

**Status Filter:**
- 🔵 All Targets - Show all targets
- 🟢 Completed - Show rated targets only
- 🟠 Not Completed - Show unrated targets only

## Common Use Cases

### 1. "What do I still need to complete?"

**Steps:**
1. Click **"Not Completed"** status filter
2. All unrated targets will be displayed
3. Start rating from top to bottom

**Result:** Focus on pending work only

---

### 2. "Show me all my completed Strategic targets"

**Steps:**
1. Click **"Strategic"** category filter
2. Click **"Completed"** status filter
3. View all rated strategic targets

**Result:** See your completed strategic work

---

### 3. "How many Core targets do I have left?"

**Steps:**
1. Click **"Core"** category filter
2. Click **"Not Completed"** status filter
3. Check the badge count

**Result:** Badge shows exact number remaining

---

### 4. "Review all my ratings"

**Steps:**
1. Click **"All"** category filter
2. Click **"Completed"** status filter
3. Scroll through all rated targets

**Result:** See all your completed work

---

### 5. "Start fresh - rate everything"

**Steps:**
1. Click **"All"** category filter
2. Click **"All Targets"** status filter
3. Rate targets one by one

**Result:** See complete list of all targets

---

## Tips & Tricks

### Tip 1: Track Your Progress
- Use "Not Completed" filter to see remaining work
- Badge count shows exactly how many left
- Work through them systematically

### Tip 2: Review Before Submitting
- Use "Completed" filter to review all ratings
- Verify all targets are rated correctly
- Check for any mistakes before final submission

### Tip 3: Focus on One Category
- Select a category (e.g., Strategic)
- Complete all targets in that category
- Move to next category

### Tip 4: Quick Status Check
- Look at badge counts without clicking
- "Not Completed: 0" means you're done!
- "Completed: X" shows your progress

### Tip 5: Empty State Means Success
- If "Not Completed" shows empty state
- Congratulations! All targets are rated
- Ready to submit your IPCR

## Keyboard Shortcuts

While filters don't have keyboard shortcuts yet, you can:
- Tab through filter buttons
- Press Enter/Space to activate
- Use arrow keys to navigate

## Mobile Usage

On mobile devices:
- Filters wrap to multiple rows if needed
- Tap any filter button to activate
- Scroll horizontally if filters overflow
- Badge counts remain visible

## Troubleshooting

### "No targets found"
**Cause:** No targets match your filter combination  
**Solution:** Try different filter combination or check if targets exist

### "Badge count seems wrong"
**Cause:** Targets may have been recently rated  
**Solution:** Refresh the screen or check target ratings

### "Filter not working"
**Cause:** May need to refresh data  
**Solution:** Pull down to refresh or restart app

## Best Practices

1. **Start with "Not Completed"** - Focus on what needs to be done
2. **Work by Category** - Complete one category at a time
3. **Review with "Completed"** - Check your work before submitting
4. **Use Badge Counts** - Track progress at a glance
5. **Reset to "All"** - Get full overview when needed

## Progress Tracking

### Daily Workflow

**Morning:**
1. Open My IPCR
2. Select "Not Completed"
3. Note the count (e.g., 8 remaining)

**During Day:**
4. Rate targets as you complete work
5. Check count periodically

**End of Day:**
6. Select "Not Completed" again
7. See reduced count (e.g., 5 remaining)
8. Track daily progress

### Weekly Review

**Monday:**
- Check "Not Completed" count
- Set weekly goal

**Friday:**
- Review "Completed" targets
- Verify all ratings are accurate
- Plan next week's targets
