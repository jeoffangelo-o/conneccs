## Tips for Secretaries

### Best Practices

1. **Review All Documents First**
   - Click each document before rating
   - Check if evidence supports the self-rating
   - Look for completeness and quality

2. **Use Preview in Rating Modal**
   - Documents are accessible while rating
   - No need to go back to main view
   - Quick reference while entering scores

3. **Multiple Document Review**
   - Review all documents for a target
   - Compare evidence across documents
   - Ensure consistency

4. **Document Verification**
   - Check file names match descriptions
   - Verify document dates
   - Confirm relevance to target

### Keyboard Shortcuts (Web)

- `Esc` - Close preview modal
- `Click` - Open document
- `Ctrl/Cmd + W` - Close document tab

## Troubleshooting

### Document Won't Open
**Problem**: Clicking "Open Document" does nothing
**Solution**: 
- Check if pop-up blocker is enabled
- Allow pop-ups for this site
- Try right-click → "Open in new tab"

### Wrong File Type Icon
**Problem**: PDF shows as generic document icon
**Solution**: 
- File extension might be missing
- Check file name includes .pdf
- Icon is cosmetic, doesn't affect functionality

### Document Opens as Download
**Problem**: File downloads instead of opening
**Solution**: 
- This is normal for some file types
- Office files may download on some browsers
- PDF should open in browser

### Can't See Documents
**Problem**: No documents showing for target
**Solution**: 
- Target may not have documents uploaded
- Check with faculty if documents are missing
- Can still rate without documents (if appropriate)

- **Larger Touch Targets**: Document cards are bigger on mobile

- **Share Option**: Can share document from system viewer

- Modal has proper ARIA labels

- Tab through documents

- Escape to close modal
- Focus returns to trigger element
