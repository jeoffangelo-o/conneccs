STEP 1: Stop & Restart Dev Server
─────────────────────────────────
In your terminal:
1. Press Ctrl + C to stop
2. Run: npx expo start --clear
3. Wait for "Metro waiting on..." message

STEP 2: Clear Browser Cache (CHOOSE ONE METHOD)
────────────────────────────────────────────────

METHOD A: Incognito Window (EASIEST!)
  1. Press Ctrl + Shift + N (Chrome) or Ctrl + Shift + P (Firefox)
  2. Go to http://localhost:8081
  3. Done! No cache in incognito mode.

METHOD B: DevTools Hard Reload (BEST)
  1. Press F12 to open DevTools
  2. Right-click the refresh button (next to address bar)
  3. Select "Empty Cache and Hard Reload"

METHOD C: Keyboard Shortcut
  Press Ctrl + Shift + R (Windows) or Cmd + Shift + R (Mac)

METHOD D: Clear All Cache
  1. Press Ctrl + Shift + Delete
  2. Select "Cached images and files"
  3. Select "All time"
  4. Click "Clear data"
  5. Then press Ctrl + Shift + R

STEP 3: Verify Fix
──────────────────
1. Open DevTools Console (F12)
2. Look for: "🔄 ReportorialFolderScreen loaded - Version 2.0 (Fixed)"
3. Navigate to Reportorial Requirements
4. Click any requirement card
5. Should open WITHOUT StyleSheet error!
