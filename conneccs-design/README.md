# ConneCCS Static Design Mockup

This is a static HTML mockup of the ConneCCS Faculty Portal with the same design as the original project.

## Pages Included

- **index.html** - Login page with demo accounts
- **dashboard.html** - Main dashboard with stats and recent activity
- **faculty.html** - Faculty directory with cards
- **announcements.html** - Announcements list
- **reports.html** - Reports management table
- **ipcr.html** - IPCR monitoring (to be added)
- **documents.html** - Document folders (to be added)
- **messages.html** - Messaging system (to be added)
- **workload.html** - Workload management (to be added)

## Features

- ✅ Same design and styling as original
- ✅ Dark/Light theme toggle
- ✅ Responsive layout
- ✅ Static data for demonstration
- ✅ No backend functionality (mockup only)
- ✅ All navigation links work between pages

## How to Use

1. Open `index.html` in a web browser
2. Click any demo account button or "Sign In" to go to dashboard
3. Navigate between pages using the sidebar menu
4. Toggle theme using the sun/moon icon in the sidebar
